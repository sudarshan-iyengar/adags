# LGS — Refinement and Adversarial Review History (durable record)

Date: 2026-08-08. Reviewer: GPT-5.6-Sol via Codex MCP at xhigh
reasoning. Two stages, mirroring the project's standing protocol:
same-thread refinement, then FRESH-context adversarial rounds (no shared

## Stage 1 — research-refine loop (4 rounds, one thread)

Candidate: RE-GS (recurrent-element factorization, dossier v2 from the
representation-first ideation). Scores 7.2 REVISE → 8.3 → 8.8 → 9.2
READY. Decisive contributions of the loop (all adopted): exclusive-
winner rendering semantics; per-instance geometric pose; signed
accumulator statistics; fixed-graph isolation protocol; ordered
interval parameterization; reference-instance gauge; finite terminal
endpoints; lineage-aware densification (anti-flipbook escape hatch);
narrowed claims. The loop's READY verdict did NOT predict fresh-context
survival — reconfirming the project rule.

## Stage 2 — fresh-context adversarial rounds

### Round 1: RE-GS v5 — SINKS (hostile novelty estimate 4/10)
Three reject-level defects: (a) recurrence topology UNREACHABLE
(fission only splits already-tracking lineages; new-birth reappearances
can never rejoin — no merge/extension path); (b) LoRA re-centering bug
(copied coefficients do not preserve motion under a changed temporal
center; no exact transform for a learned basis); (c) endogenous
isolation (tied model generates both the graph and the evaluation
mask). Plus: sigmoid tails ⇒ no exact absence state and inevitable
argmax ties; positive-only trigger discards presence-supporting
gradients; invalid confidence claims; occlusion-vs-absence conflation;
novelty reduced to "weight tying + bookkeeping" against canonical-
deformation/avatar/codec ancestry.

### Round 2: LGS v6 — SINKS (5/10)
v6's fixes (compact support, fixed element origin, extension op,
per-scalar economics) were attacked: ratio economics undefined for
zero/negative-cost ops and gameable; cheap reuse ≠ identity; interval
invariants not optimizer-proof under absolute endpoints; fixed
per-ELEMENT origin destroys far-episode motion expressivity;
reachability still requires six simultaneous successes. Reviewer's
viability prescription recorded verbatim: narrow to predictive
cross-episode parameter sharing; complete resource-aware objective;
mathematical interval invariants; merge/global association or sharply
limited identity claim.

### Round 3: LGS v7 (soft content assignment) — SINKS (4/10)
The differentiable-association pivot introduced its own fatal defects:
no coherent geometry under cross-entry migration (gauge transport
undefined); cap/correctability contradiction; mixture semantics
undefined; structural vs content lineage conflated. Full findings in
[[operations/rejected-representations-2026-08]] item 4.

### Round 4: LGS v8 (kernel form) — SINKS for the search layer only
"These defects sink the current system/search paper, but NOT the
representation kernel" — hostile novelty estimate RAISED to 7/10.
Two remaining sinkers, both with reviewer-named fixes: (a) removal
score sign/compositing bug (deleting contribution P changes loss by
≈ ∇L·(−P), and deletion reveals background) → counterfactual
micro-render scoring; (b) reactivation retrieval undefined →
deterministic dormant-candidate indexing. Also: exact initialization,
precise schedule state machine, Pareto kill rule vs grouping controls.

### Round 5: LGS v9 — SURVIVES-WITH-RISKS (hostile estimate 5.5/10)
"There is no single unrepairable mathematical defect." Binding survival
conditions (carried into [[operations/lgs-experiment-plan]]):
(1) substantial legitimate multi-episode activation on several real
scenes; (2) quality-vs-total-memory advantage surviving untied +
capacity-matched random-grouping + wrong-grouping controls with the
backbone below the frontier; (3) evidence the search discovers useful
episodes beyond annotation-selected cases. Repairable spec items (len
floor threshold, bounded endpoint transforms, τ creation rules,
re-anchoring equations, inner rollout for additions, episode-onset
holdouts, multi-point Pareto frontiers, annotation-use prohibitions,
scoped evaluator claims) — all folded into [[operations/lgs-method]].
Top residual risks, ranked: mechanism-benchmark mismatch (activation
rarity on N3V); myopic acceptance bias vs additions; no-merge
irreversibility; post-treatment graph-source bundle in the 2×2;
hard-sharing misspecification under pose/illumination change.

## Cross-cutting conclusion (durable)

Across nine reviewer passes (4 refine + 5 fresh), the REPRESENTATION
KERNEL — compact-support multi-episode presence with exact absence +
hard cross-episode radiance tying + episode-local pose/motion — was
conceded unoccupied by every fresh reviewer, while every discovery
mechanism bolted onto it sank until demoted to honest supporting
machinery with trial-render confirmation. Claim-inflation was again the
recurring fatal pattern (exactness, calibration, "one principle",
identity language); the surviving form states only what the math
delivers. Fresh-context adversarial review remains the binding standard.
