## 3. The method (v3, post-training edit)

### 3.1 B1 — observation-born packet birth (public ingredient, supporting)

Budget-neutral spacetime relocation on the existing point-neutral
transaction substrate, during training: every R iterations in the
densification window, bottom-q% (opacity x radius) donors relocate to
high photometric-error dynamic-mask pixels backprojected through
rendered depth at the training timestamp; relocated rows get xyz=site,
t-mean=t, narrow t-scale (1-2 frame sigma), observed-pixel DC, reset
opacity; each event stamps a PACKET id (per-row long column, -1 =
substrate; inherited by clone/split; refined at birth by spatial
connected components). Zero net capacity change. Precedents disclosed:
FreeTimeGS relocation scoring, CEC-4DGS rendered-depth birth.

### 3.2 B2 — the consolidation pass (the contribution)

Runs ONCE, post-training, on the FROZEN final B1 state:

1. packets/descriptors from the final state (descriptor: mean DC,
   SH-band energy, mean scale, dominant normal, footprint
   centroid/extent, temporal interval; per-row medoid-consistency gate);
2. proposals: mutual-nearest descriptor matching between packets with
   temporal supports separated by >= 2 frames (effective supports at a
   DECLARED cutoff, mu +/- 2 sigma_t); K<=3 per packet, P<=128
   evaluated; donor = the packet with more training-view observations;
   row map f: recipient-row -> donor-row by nearest-descriptor at
   proposal time; one-hop only (rows with incoming pointers ineligible
   as recipients; donors ineligible as recipients);
3. sequential admission in ONE PRESPECIFIED ORDER (descending descriptor
   score, frozen before any confirmation render), each edge tested
   against the state containing all previously accepted edges, on that
   decision's DISJOINT reserved slot (>= 16 units, >= 6 per episode
   side, from the pre-partitioned reserved pool never used in training);
   admission rule (a PREREGISTERED SELECTION RULE, not an inferential
   guarantee): paired per-unit photometric delta, admit iff
   mean + 3*SE < 0 AND each episode-side mean <= 0 (descriptive screens,
   labeled as such);
4. ONE final joint comparison B2-state vs original B1-state on a
   held-back joint-veto reserve partition no per-edge decision saw:
   frozen rule in §6.1; fail => the WHOLE edit set is rejected
   (B2 := B1); no subset salvage, no retest, single access;
5. output: B2 differs from B1 by the pointer/mode columns ONLY —
   verified by hashing the frozen state before and after, excluding
   only those columns and search metadata.

Rendering under a tie: **directional donor DC reuse** (primary arm) —
recipient rows render with the donor's DC/base radiance, keeping their
own higher-order SH, geometry, opacity, routing, motion, temporal lobe.
Secondary prespecified ablation: full-SH substitution. **The two arms
are SEPARATE consolidation runs from the same B1 state** (own sequential
state, own joint veto); the promotion claim rides on the DC arm alone;
no post-hoc fallback between arms.

## 5. What is given up, disclosed

Post-training editing means no co-adaptation: geometry cannot adjust to
reused appearance, and donors gain nothing. CCR v3 measures pure
certified reuse on the final state — the cleanest attributable version,
and the weakest. A training-time variant (gradient-open, audited) is
future work requiring trajectory-level validation; the 3-round review
record documents exactly why it was not attempted first (transplant
certificates do not certify optimization trajectories).

## 6. The three frozen clauses (review round 3 blockers)

1. **Joint veto**: loss = the same paired per-unit photometric delta
   used per-edge, unweighted mean over ALL units of the veto partition
   (whole-frame rays, both episodes of every admitted edge included by
   construction of the partition); pass iff mean(B2-B1) <= 0; equality
   passes; any NaN/missing unit => fail closed; minimum 32 units or the
   pass refuses to run; comparison is against the ORIGINAL B1 state;
   one access, all-or-nothing.
2. **Arms**: B2-DC and B2-full are separate runs from the same B1
   state; mode encoded per run, never mixed within a deployed state.
3. **Per-seed non-catastrophe** in the promotion gate (§4).
