# 4C4D: 4 Camera 4D Gaussian Splatting

**Paper:** https://arxiv.org/abs/2604.04063
**Code:** https://github.com/yangzf-1023/4C4D
**Base method:** Native 4D Gaussian Splatting with 4D rotation and marginalized temporal opacity (Yang et al. 2024, "Real-time Photorealistic Dynamic Scene Rendering with 4D Gaussian Splatting" — `rot_4d`, `gaussian_dim=4`, `sh_degree_t`, `get_marginal_t` in the released code all match this lineage), itself extending 3D Gaussian Splatting (Kerbl et al. 2023). Sparse-camera point initialization uses MAST3R.

## One-line thesis

A per-Gaussian learned opacity-decay factor, applied only to Gaussians that are currently in-frustum and temporally active, redistributes optimization gradient toward geometry rather than appearance — because unconditional/constant decay instead corrupts Gaussians that happen to have no rendering gradient this step.

## Problem / Gap

Under extremely sparse capture (as few as 4 cameras vs. the 18–24 used by Neural3DV/ENeRF-style rigs), 4DGS and 4DGaussians overfit appearance from the few available views while leaving geometry (and thus novel-view quality) weak, because photometric loss alone gives Gaussians no explicit pressure to commit to a single geometrically-consistent position. Naively adding a global/constant opacity decay to counter this (as in prior opacity-reset heuristics) perturbs Gaussians uniformly, including ones that are out of frustum or temporally inactive for the current training view and therefore have no gradient signal to justify or correct the perturbation.

## Method

4C4D keeps the standard 4DGS pipeline (native 4D position/rotation/opacity, temporal marginal opacity weight) and inserts one addition at render time: a lightweight "Coefficient" MLP (the Neural Decaying Function) maps each Gaussian's opacity, 4D position, and 4D scale to a scalar decay factor. Per render call, a visibility mask is computed as CUDA frustum-culling (`markVisible`, view/projection-matrix based) on Gaussian centers, ANDed with a temporal-activity test (marginalized temporal opacity weight above a threshold). Only Gaussians passing this mask get their opacity multiplied by the learned decay factor before rasterization; Gaussians outside the mask keep their existing opacity unchanged for that step. The Coefficient MLP and the Gaussians are optimized jointly through the same photometric rendering loss, with no separate loss term for decay.

## Assumptions

Requires a small set of synchronized, calibrated, static cameras (4 up to 24 in the paper's benchmarks) around a per-scene capture; optimization is fully photometric and per-scene (no cross-scene generalization), and sparse-camera runs additionally rely on MAST3R for initial point-cloud stability.

## Limitations / Failure Modes

The paper does not include a dedicated failure-mode/limitations discussion. Mechanistically, the visibility test is pure frustum + temporal-span membership (a CUDA `markVisible` call plus a `marginal_t > 0.05` threshold) with no depth-order or occlusion reasoning, so two Gaussians visible in the same view at different depths are treated identically by the decay policy. The mechanism only modulates the opacity of existing primitives during training; it never creates, retires, or reassigns primitives to represent geometry that becomes hidden or revealed over time.

## Reusable Ingredients

- **Mask-gated per-primitive gradient policy**: apply a learned operator only to primitives passing a cheap visibility test, leave others untouched for that step, rather than perturbing all primitives uniformly.
- **Frustum ∩ temporal-span visibility as a training-time filter** (not just a render-time culling optimization) — reuses existing 4DGS marginal-opacity math as a free temporal-activity signal.
- **Ablating the shape of a scalar modulation function**: comparing a learned MLP against constant/power/exponential closed-form decay curves isolates whether "learned" vs. "hand-tuned" schedule shape is what matters.
- **Decoupling opacity-saturation control from periodic hard resets**: replacing interval-based `reset_opacity()` with a continuous per-step, visibility-gated multiplicative decay.

### Deep Dive

#### Core Novelty
Relative to base 4DGS, 4C4D adds exactly one learned component — a scalar decay-factor MLP — and one gating rule — apply it only where a Gaussian is currently visible in both space and time. The insight is that a fixed/global decay schedule (constant, power, exponential) can't tell which Gaussians currently have a supervising gradient; gating a *learned* factor by visibility lets the network suppress appearance-driven opacity inflation specifically where the photometric loss can currently see and correct it, while leaving temporarily invisible Gaussians alone rather than mis-attenuating them.

#### Mathematical Formulation

Visibility set, evaluated per render call (per camera, per timestep) before rasterization:
$$V = \{\, g : \mathrm{markVisible}(x_g, y_g, z_g;\, V_\text{cam}, P_\text{cam}) \ \wedge\ w_g(\tilde t) > 0.05 \,\}$$
where `markVisible` is a CUDA frustum-culling test against the camera's view/projection matrices, and $w_g(\tilde t) = \exp\!\big(-\tfrac{1}{2}(t_g-\tilde t)^2/\sigma_{t,g}\big)$ is the base 4DGS temporal marginal-opacity weight (pre-existing mechanism, reused here only as a temporal-activity threshold; $\sigma_{t,g}$ is the Gaussian's temporal-covariance entry).

Decay factor, evaluated per Gaussian, only for $g \in V$:
$$\tau_g = f_{min} + (f_{max}-f_{min})\cdot \mathrm{MLP}_\theta\big(2o_g-1,\ \bar p_g,\ \bar s_g\big)$$
$$o_g \leftarrow \tau_g \cdot o_g \quad \text{for } g \in V; \qquad o_g \leftarrow o_g \quad \text{for } g \notin V$$
where $o_g$ is current opacity, $\bar p_g$ is the batch-normalized 4D position $(x,y,z,t)$ ($(p-\mu_p)/\sigma_p$ across all Gaussians), $\bar s_g$ is the batch-normalized log 4D scale $(\log s_x, \log s_y, \log s_z, \log s_t)$, $f_{min}=0.996$, $f_{max}=0.998$, and $\mathrm{MLP}_\theta$ outputs a sigmoid in $[0,1]$. This is evaluated inside the render forward pass, replacing `pc.get_opacity` for that step's rasterization, and is applied jointly with (i.e. multiplicatively on top of) the standard 4DGS temporal marginal-opacity weight already baked into the base rasterizer.

#### Algorithm / Pipeline Changes
1. When `--opacity_decay` is enabled (default true), instantiate the Coefficient MLP alongside the `GaussianModel` and give it its own Adam optimizer (separate param group from Gaussian attributes).
2. Inside `render()`, once `iteration > decay_from_iter` (default 500): compute frustum visibility via `rasterizer.markVisible(means3D)`; if `--time_aware` (default true), additionally compute `pc.get_marginal_t(timestamp)[:,0] > 0.05` and AND the two masks together.
3. Rescale opacity to $[-1,1]$ ($2o-1$), concatenate with the per-batch-normalized 4D position and normalized log 4D scale into a 9-dim vector, and feed it through the Coefficient MLP.
4. Map the MLP's sigmoid output into $[f_{min}, f_{max}]$ and multiply it into the opacity of only the visibility-masked Gaussians (`torch.where(mask, curr_opacity, old_opacity)`); the write-back happens in-place via the inverse opacity activation.
5. The resulting opacity tensor feeds directly into that same iteration's rasterization call — there is no separate decay loss; gradients reach the Coefficient MLP only through the photometric loss on the rendered image.
6. Because `opacity_decay` provides continuous saturation control, the standard periodic `reset_opacity()` call (every `opacity_reset_interval`, default 3000 iters) is skipped entirely while it is enabled, and the size-based pruning threshold that normally activates after that interval is forced to `None`.

#### Key Hyperparameters & Design Choices
- Coefficient MLP: 2-layer, `Linear(9→32) → ReLU → Dropout(0.1) → Linear(32→1) → Sigmoid`; input is opacity (1) + 4D position (4) + 4D log-scale (4) = 9 dims. Rotation is not an input despite being mentioned in secondary descriptions of the method — the released code never passes rotation to this module.
- Decay bounds: $f_{min}=0.996$, $f_{max}=0.998$.
- `decay_from_iter = 500` (decay mechanism only activates after this many iterations).
- Temporal-visibility threshold: marginal opacity weight $> 0.05$.
- Coefficient optimizer: Adam, `coefficient_lr = 1e-5`, `coefficient_weight_decay = 1e-4` (both distinct from the Gaussian attribute learning rates, e.g. `opacity_lr=0.05`).
- Total training: 30,000 iterations; `densify_until_iter=15000`; `opacity_reset_interval=3000` (bypassed when opacity_decay is active).
- Ablated alternative decay-mode shapes (same code path, different `mode` argument): `const` ($o\cdot f_{min}$), `power_desc`/`power_asc` ($o\cdot(f_{min}+(f_{max}-f_{min})(1-o)^p)$ or its ascending counterpart), `exp_desc`/`exp_asc` (exponential-weighted variants), all with a shared exponent/shape parameter $p$; "Not specified in paper" for the exact $p$ values used in the reported ablation.

#### Ablation Summary
(Neural3DV; PSNR / LPIPS)
1. **Neural Decay removed** (`w/o Neural Decay`): 22.60 / 0.147 — **largest drop, −2.08 dB vs. full method**; flagged as the single most impactful component.
2. **Visibility Detection removed** (`w/o Visibility Detection`): 24.49 / 0.127 — −0.19 dB vs. full method; smaller than removing decay itself, but still degrades LPIPS notably.
3. **Full method** (both components): 24.68 / 0.115.

Decay-function shape ablation (Table 5, same benchmark):
- Constant decay ($\beta=0.9$): 24.31 / 0.125
- Power decay: 24.35 / 0.124
- Exponential decay: 24.32 / 0.135
- Learned Neural Decay (used in full method): 24.68 / 0.115 — outperforms every hand-designed closed-form schedule by at least +0.33 dB.

#### Implementation Reality
- **Framework:** PyTorch + custom CUDA, extending a native-4D-Gaussian `diff-gaussian-rasterization` fork (adds `ts`, `scales_t`, `rotations_r`, and a `flow_2d` output/input beyond stock 3DGS rasterization).
- **Key files:** `module/__init__.py` (the `Coefficient` class — the entire Neural Decaying Function, ~35 lines); `gaussian_renderer/__init__.py` (computes the visibility mask and calls `pc.opacity_decay(...)` inside `render()`); `scene/gaussian_model.py` (`opacity_decay` method implementing all 7 decay modes — `const`, `exp_asc`, `exp_desc`, `mlp`, `net`, `power_desc`, `power_asc` — used for both the main method (`net`) and the Table 5 ablation); `train.py` (CLI defaults: `--opacity_decay` true, `--f_min 0.996`, `--f_max 0.998`, `--decay_from_iter 500`, `--time_aware` true).
- **Notable implementation details:** invisible Gaussians are not decayed by any separate constant factor each step — the code simply leaves their opacity untouched (`torch.where(mask, curr_opacity, old_opacity)`) whenever they fail the visibility mask, so decay only accumulates across the renders/timesteps in which a Gaussian is actually visible. The repo ships per-scene configs for the exact Neural3DV scenes ADAGS works with, including `cut_roasted_beef.yaml`, `flame_steak.yaml`, and `sear_steak.yaml`.
